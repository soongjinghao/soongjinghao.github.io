# 项目简介

我的个人主页，主要用于展示个人简介、教育经历、项目经历、技术栈、竞赛经历与近期动态。

🌐 **在线访问：** https://soongjinghao.github.io/


## 项目结构

```text
song-jinghao.github.io/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── images/
        └── avatar.svg
```

## 快速开始

克隆项目：

```bash
git clone https://github.com/soongjinghao/soongjinghao.github.io.git
cd soongjinghao.github.io
```

可以直接打开 `index.html` 进行预览，也可以启动一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```
